# EmpowerHer: code layout

EmpowerHer is a **Django** project, with **no React**. One Django server provides both the web pages (frontend) and the JSON REST API (backend). The two are kept in separate folders:

```
empowerher/backend/
├── manage.py            run commands: runserver, test, migrate, seed_demo, run_benchmarks
├── requirements.txt     Python packages
├── .env                 secret keys (never commit; created by setup.sh)
│
├── config/              PROJECT SETTINGS + SHARED HELPERS
│   ├── settings.py          settings: apps, security, database, static files
│   ├── urls.py              routing: pages -> frontend/urls.py, /api/... -> apps/*/urls.py
│   ├── authentication.py    login tokens that expire
│   ├── crypto.py            Fernet encryption helpers
│   ├── datasets.py          reads files from datasets/
│   └── testing.py           helpers used by the tests
│
├── apps/                BACKEND (Python): one folder per feature
│   ├── users/           register, login, profile, password, export, delete account
│   ├── business/        business idea validation (+ confidential mode, AI advice)
│   ├── schemes/         government schemes + recommender
│   ├── funding/         EMI, affordability, PMEGP calculators
│   ├── privacy/         Paillier homomorphic encryption (private loan check)
│   ├── market/          local market demand (Census 2011 + MSME data)
│   ├── documents/       document upload, OCR, ID number checks, encrypted storage
│   ├── idea_vault/      encrypted ideas + zero-knowledge ownership proofs
│   ├── assistant/       English / Telugu / Hindi assistant
│   └── safety/          helplines and safety guides
│
├── frontend/            FRONTEND (HTML + JavaScript): what users see
│   ├── urls.py          which URL shows which page (table of pages -> APIs inside)
│   ├── views.py         renders the pages
│   ├── templates/       one HTML file per page; base_app.html is the shared layout
│   └── static/js/       paillier.js (encryption that runs in the browser)
│
└── datasets/            DATA the backend reads
    ├── raw/             original downloads (Census 2011, Ministry of MSME PDF)
    ├── processed/       CSVs built by build_datasets.py
    └── curated/         schemes, loan products, safety resources (JSON)
```

## Inside each backend app

| File | What it does |
| --- | --- |
| `urls.py` | the app's API routes, mounted at `/api/<name>/` |
| `views.py` | API endpoints: check login and permissions, validate input, call the logic, return JSON |
| logic file, e.g. `recommender.py`, `calculator.py`, `paillier.py`, `zkp.py`, `ocr.py` | the algorithm itself, with no web code |
| `models.py` | database tables (only for apps that store data) |
| `tests.py` | automated tests (`python manage.py test`) |
| `migrations/` | database schema history (generated by Django) |

## How the frontend and backend work together

```
Browser                         frontend/                       apps/
───────                         ─────────                       ─────
GET /schemes/        ──────►  urls.py -> templates/schemes.html
(page loads)
JavaScript fetch()
GET /api/schemes/recommend/ ──────────────────────────────────►  schemes/views.py
  Authorization: Token …                                          -> recommender.py
◄────────────────────────────── JSON ────────────────────────────
page shows the results
```

**Where to find each feature:**

| Feature | Page (frontend) | API + logic (backend) |
| --- | --- | --- |
| Login / register / profile | `templates/login.html`, `register.html`, `profile.html` | `apps/users/` |
| Business idea validation | `templates/business_validation.html` | `apps/business/views.py` |
| Government schemes | `templates/schemes.html` | `apps/schemes/recommender.py` |
| Funding + private HE check | `templates/funding.html`, `static/js/paillier.js` | `apps/funding/calculator.py`, `apps/privacy/paillier.py` |
| Market demand | `templates/market.html` | `apps/market/analysis.py` |
| Documents | `templates/documents.html` | `apps/documents/ocr.py`, `validators.py` |
| Idea Vault + ZKP | `templates/vault.html`, `vault_verify.html` | `apps/idea_vault/zkp.py`, `encryption.py` |
| Assistant | `templates/assistant.html` | `apps/assistant/engine.py` |
| Safety | `templates/safety.html` | `apps/safety/views.py` |
